# Lumen Volley

Full-colour Python 3 neon vertical volley arcade for ElbowOS.

Control the bottom paddle. Rally the neon ball past the magenta opponent.
A / D or Left / Right move. R restart. Esc quit.

## Play

```
pip install -r requirements.txt
python3 lumen_volley.py --play
```

## Record a 9:16 reel

```
python3 lumen_volley.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
